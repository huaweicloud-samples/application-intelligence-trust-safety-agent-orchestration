# 架构说明

## 系统架构

Trust & Safety Orchestration Agent 是一个事件驱动的多智能体编排系统，运行在华为云上。

## 核心组件

### 1. 事件接入 (DIS)

- 接收来自各种来源的行为事件
- 触发 FunctionGraph 函数进行预处理
- 支持高吞吐量流处理

### 2. 调查工作流 (FunctionGraph DAG)

- 并行收集多维度证据
- 置信度评分计算
- 策略引擎路由决策

### 3. 数据存储

- **GaussDB-Mongo**: 案例、证据元数据、审计日志
- **OBS**: 大文件证据、审计归档
- **DCS**: 限流、缓存、会话管理

### 4. API 层 (APIG)

- REST API: CRUD 操作
- WebSocket: 实时仪表盘更新

### 5. 前端仪表盘

- React + TypeScript
- 实时事件展示
- 案例管理

## 事件流程

1. **检测阶段**: 事件流入 DIS，FunctionGraph 进行异常评分
2. **调查阶段**: 触发 DAG 工作流，并行收集证据
3. **决策阶段**: 置信度计算，策略引擎决定执行路径
4. **执行阶段**: 自动执行或升级到人工审查

## 安全最佳实践

- 所有 FunctionGraph 函数使用最小权限 IAM 策略
- GaussDB 表加密存储
- OBS 桶强制加密和阻止公共访问
- API 端点需要认证 (JWT)
- 审计日志不可变 - 审计日志失败则执行中止
- 敏感案例始终升级到人工审查
